# Bot Arena Prototype

Прототип приложения для хранения и представления данных платформы запуска пользовательских ботов для бесконечных крестиков-ноликов.

## Стек

- React + Vite - веб-интерфейс
- Python - backend
- FastAPI - REST API
- MongoDB - хранение ботов, версий, матчей, событий и логов
- Docker Compose - запуск приложения

## Запуск

```bash
docker compose build --no-cache
docker compose up
```

После запуска интерфейс доступен по адресу:

```text
http://127.0.0.1:3000
```

API доступно по адресу:

```text
http://127.0.0.1:8000/api/health
```

## Отладочные пользователи

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@arena.local | admin123 |
| Модератор | moderator@arena.local | moderator123 |
| Пользователь | user@arena.local | user123 |

## Роли и права

| Роль | Доступные действия |
|---|---|
| Пользователь | вход, регистрация, просмотр ботов, карточек ботов, матчей, статистики, создание матча |
| Модератор | всё из роли пользователя, загрузка и редактирование ботов, просмотр и редактирование логов, импорт/экспорт, отчёты, анализ, изменение настроек выполнения |
| Администратор | всё из роли модератора, управление пользователями и выдача ролей |

При регистрации новый аккаунт получает роль `user`. Роль можно изменить в разделе "Настройки" под пользователем с ролью администратора.

## Реализованные сценарии

### 0. Вход в систему

Пользователь вводит email и пароль, система проверяет данные и открывает главную страницу. При неверных данных показывается сообщение об ошибке.

### 0a. Регистрация

Пользователь создаёт аккаунт через форму регистрации. Новый аккаунт сохраняется с ролью `user`.

### 1. Загрузка бота

Модератор или администратор может загрузить Python-файл бота, заполнить название, версию, теги, описание и комментарий. Файл сохраняется как активная версия бота.

### 2. Поиск ботов по полям

На странице "Боты" доступны поиск и фильтры по идентификатору, названию, языку, версии, статусу, тегам и владельцу.

### 3. Просмотр карточки бота

Карточка бота показывает свойства, описание, файл, статистику, связанные матчи и настройки запуска. Для загруженного файла доступно скачивание. Модератор и администратор могут редактировать карточку и заменить данные бота.

### 4. Создание матча

Пользователь выбирает двух ботов, размер поля, условие победы и лимиты запуска. При создании матча система запускает партию между активными версиями выбранных ботов.

### 5. Просмотр карточки матча и истории статусов

Карточка матча показывает участников, правила, результат, победителя, историю статусов, replay-поле с координатами, список ходов и технические сообщения.

### 6. Просмотр логов

Модератор и администратор могут открыть список логов, искать по тексту и фильтровать по уровню, боту, матчу и статусу.

### 7. Просмотр лога матча

Экран лога показывает текст события, уровень, источник, связь с матчем и ботом. Есть поиск по фрагменту текста, скачивание лога и редактирование заметки.

### 8. Импорт данных

Импорт восстанавливает пользователей, ботов, версии, статистику, матчи, события, отчёты, настройки и историю операций (единый JSON-дамп приложения)

### 9. Экспорт данных

Экспорт выполняется одной кнопкой и формирует полный JSON-дамп данных приложения.

### 10. Просмотр статистики

Страница "Статистика" строит агрегаты по матчам и ботам: количество матчей, победы, поражения, ничьи, ошибки, среднее число ходов, среднюю длительность и рейтинг.

### 11. Конструктор отчёта

Модератор или администратор выбирает источник данных, метрики, группировку, фильтры и тип визуализации. Система строит предпросмотр отчёта, график или таблицу, сохраняет конфигурацию и позволяет экспортировать результат.

### 12. Настройки приложения и роли

В разделе "Настройки" доступны лимиты выполнения, лимиты памяти, параметры логирования и управление пользователями. Недоступные юзеру.

В репозитории добавлены два примера для ручной загрузки через интерфейс:

```text
examples/bots/smart_line_bot.py
examples/bots/aggressive_line_bot.py
```

## Коллекция MongoDB

Все данные приложения хранятся в MongoDB. Основные коллекции:

- `users` — пользователи и роли;
- `bots` — карточки ботов;
- `bot_versions` — версии и файлы решений;
- `bot_stats` — агрегированная статистика;
- `matches` — карточки матчей;
- `match_events` — поток ходов и логов;
- `reports` — сохранённые конфигурации отчётов;
- `import_export_history` — история импорта и экспорта;
- `app_settings` — настройки приложения;
- `log_notes` — заметки и правки логов.

При старте приложение проверяет базу. Если коллекция `bots` пустая, автоматически загружается демонстрационный набор:

- пользователи разных ролей;
- боты и версии;
- статистика;
- матчи;
- события матчей и логи;
- отчёты;
- история операций импорта/экспорта;
- настройки приложения.

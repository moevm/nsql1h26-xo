# Иттерация 1
## Тема курсовой работы
**Информационная система для бесконечных крестиков-ноликов (платформа для запуска пользовательских ботов)**

---

## Задача проекта
Разработать платформу для запуска пользовательских ботов в «бесконечных крестиках-ноликах» с возможностями:
- хранение ботов и метаданных;
- сохранение логов запусков и состояния поля;
- сбор статистики по матчам и ботам;
- поиск/фильтрация и (при необходимости) кластеризация логов и результатов.

---

## Стек технологий
- **Python** — логика, симуляция матчей, обработка логов;
- **MongoDB** — хранение ботов, матчей, логов, статистики;
- **Docker** — контейнеризация и развертывание;
- **FastAPI** — REST API;
- **React** — веб-интерфейс.

---

## Реализация текущей иттерации
- Подготовлено **Docker-окружение** для приложения и MongoDB.
- Создан базовый **Python-сервис** (каркас).
- Реализовано подключение к **MongoDB**:
  - чтение/запись тестовых данных;
  - конфигурация через **переменные окружения**.
- Подтверждён запуск сервиса в контейнере и корректное взаимодействие с базой.

---

## Видение проекта
### Основные сущности
- **Bot**
- **Match**
- **Game State**
- **Logs**
- **Statistics**

### Функциональность
- загрузка и хранение ботов;
- безопасный запуск матчей в изоляции и сохранение результатов/логов;
- REST API: боты, матчи, логи, статистика;
- аналитика: признаки из логов/ходов и кластеризация;
- UI (React): управление ботами, просмотр матчей, логи, статистика.
